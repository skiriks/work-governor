# Synthetic project brief

This is a local text-file sorting prototype. No client data or connected accounts are involved.

The eventual prototype will read files from `incoming/`, suggest names based on a supplied mapping, and place approved copies in `organized/`. Original files must remain unchanged. Existing destinations must never be overwritten. Missing or ambiguous mappings must be reported for a user decision.

For this demo, create only `AGENTS.md` containing concise instructions for a future coding agent. Do not build the sorter, create these data folders, install dependencies, use external services, or modify this brief.

The agent instructions must distinguish observed facts from assumptions, require verification appropriate to any later authorized change, and report unresolved cases. Future deletion, publishing, sends, or production use need separate authorization.
